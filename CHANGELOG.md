# @oprdev/pi-roast-mode

## 0.1.2

### Patch Changes

- Hard style is now the default roast style; the persona is sharpened to a knife-edged register (polite enough to be professional, technical enough to be trusted, rude enough to be remembered).
- Linus style is spicier: brutal, profanity-adjacent dressing-downs that stay funny to read, edge tuned to ~85-90%.

## 0.1.1

### Patch Changes

- Linus mode wordings and questions now match the hard register; every reply opens with an acknowledgment phrase.
- npm scope moved to `@oprdev`.

## 0.1.0

### Minor Changes

- Initial release: read-only `/roast` collaboration mode, with an evidence-based roast prompt, `roast_mode_question` and `roast_mode_complete` tools, `--roast` flag, and `ROAST.md` export.
